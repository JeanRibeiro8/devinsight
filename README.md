# DevInsight

DevInsight is a SaaS platform that helps engineering teams monitor development activity, analyze repositories, and receive insights about code quality and team performance.

## Features

- Engineering overview dashboard
- Repository monitoring
- Dynamic repository details
- Pull request tracking
- Pull request filters
- Code review monitoring
- AI-style recommendations using mock data
- Team contribution analytics
- Development analytics and charts
- Workspace settings
- Responsive dark SaaS interface
- React Router navigation
- Recharts data visualization
- TypeScript interfaces and typed props

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Recharts
- CSS

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

To run the linter:

```bash
npm run lint
```
